# Zou Yuyang - Project Portfolio Page

## Overview

GameVault is a command-line app for people who host game nights for friends or CCAs. It keeps track of a game
collection and quickly finds games that suit the group that turned up, by player count, play time and tags.

My main area was **finding games that fit tonight's group**: filtering the collection by player count and by the
time available, and the play time data that this depends on.

### Enhancements implemented

* **Filter by player count** (`filter COUNT`), v1.0 ([PR #18](https://github.com/AY2627S1-CS2113-T11-4/tp/pull/18))
  * What it does: shows only the games whose player range includes the number of people present,
    so the host does not have to check every box on the shelf.
  * Added `Game#fitsPlayerCount` and `GameList#filterByPlayers`, with JUnit tests for boundary cases
    (the minimum and maximum themselves, games for an exact number of players, and no matches).

* **Play time, and filtering by it** (`add ... /time MINUTES`, `filter COUNT /time MINUTES`), v2.0
  ([PR #25](https://github.com/AY2627S1-CS2113-T11-4/tp/pull/25))
  * What it does: lets the user record how long each game takes, and find games for the group that fit in the
    time available, e.g. `filter 4 /time 45`.
  * Games with no play time recorded are left out of a timed filter (so every game shown is known to fit),
    and the app says how many were left out, so the user knows why a game they expected is missing.
  * Play time is saved as an optional fourth field in the data file, so data files saved by v1.0 still load.
    I chose this format so that teammates could later add further optional fields (e.g. tags) without breaking
    old files.
  * This feature is the base that later features build on: `pick /time` (random game that fits the time) and
    `sort time` (shortest games first) both use the play time I added.

* **Shared prefix parsing** (`Parser#splitByPrefixes`), v2.0
  * Replaced the earlier `indexOf`-based parsing of `add` with one method that splits arguments by prefixes.
    Prefixes now only count as separate words, can be given in any order, and cannot be repeated.
  * This fixed a bug where a title such as `Foo/minimal` was split at `/min`, and gave clearer errors for repeated
    prefixes. The method is now used by `add`, `filter`, `pick` and `edit`, so all commands follow the same rules.
