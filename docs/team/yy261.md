# Zou Yuyang - Project Portfolio Page

## Overview

GameVault is a command-line app for people who host game nights for friends or CCAs. It keeps track of a game
collection and quickly finds games that suit the group that turned up, by player count, play time, difficulty,
tags and more.

My main area was **finding games that fit tonight's group**: filtering by player count, play time and difficulty,
keeping games that are not on the shelf out of suggestions, and the shared prefix parsing that every command uses.

### Enhancements implemented

* **Filter by player count** (`filter COUNT`), v1.0 ([PR #18](https://github.com/AY2627S1-CS2113-T11-4/tp/pull/18))
  * Shows only the games whose player range includes the number of people present.
  * Added `Game#fitsPlayerCount` and `GameList#filterByPlayers`, with JUnit tests for boundary cases.

* **Play time, and filtering by it** (`add ... /time MINUTES`, `filter COUNT /time MINUTES`), v2.0
  ([PR #25](https://github.com/AY2627S1-CS2113-T11-4/tp/pull/25))
  * Finds games for the group that fit in the time available, e.g. `filter 4 /time 45`.
  * Games with no play time recorded are left out of a timed filter, and the app says how many, so the user
    knows why a game they expected is missing. Old data files without a play time still load.
  * Later features build on it: `pick /time`, `sort time` and `edit /time` all use the play time I added.

* **Lending games to friends** (`lend INDEX /to NAME`, `return INDEX`, `lentout`), v2.1
  ([PR #50](https://github.com/AY2627S1-CS2113-T11-4/tp/pull/50))
  * Records who has a game, and leaves lent games out of `filter`, `filter /tag` and `pick`, naming them and their
    borrowers in a note.
  * Added the shared availability check (`Game#isAvailable()`, `GameList#filterAvailable...`). A teammate's
    "unavailable game" feature (#61) built directly on it, so both features share one definition of "available".
  * Reworked the design after team review: switched to the shared named-field data format, kept the general
    `filterByPlayers` unchanged, moved the shared note-building into `GameList`, and gave each command its own tests.

* **Difficulty levels** (`/diff easy|medium|hard` on `add`, `edit`, `filter`, `pick`), v2.1
  ([PR #65](https://github.com/AY2627S1-CS2113-T11-4/tp/pull/65))
  * Lets a host avoid games too complicated for new players, e.g. `filter 4 /time 45 /diff easy`.
  * The notes that explain missing games (no play time, no difficulty, lent out) only count games that could
    have matched the other conditions, so they never point at a game the user would not have wanted anyway.

* **Shared prefix parsing** (`Parser#splitByPrefixes`), v2.0 onwards
  * One method that splits arguments by prefixes, now used by every command that takes prefixes. Prefixes only
    count as separate words, can be given in any order and in any case (e.g. `/TIME`), and cannot be repeated.
  * Fixed a bug where a title such as `Foo/minimal` was split at `/min`.
