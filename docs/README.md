# GameVault

GameVault is a command-line app for people who host board game nights for friends, family or a CCA.
It keeps track of your game collection and answers the question every host faces when the group arrives:
*what can we play tonight?* If you can type fast, GameVault gets you there faster than looking through the boxes
on your shelf.

With GameVault you can:

* **Find a game that fits tonight's group**: filter by number of players, time available, difficulty or tag
  (e.g. `filter 6 /time 45 /diff easy`), or let GameVault `pick` one at random.
* **Keep track of what you play**: log play sessions, see each game's history and when it was last played, and
  find games you have never played.
* **Let the group's favourites come up more often**: rate games after playing, and `pick` favours the ones your
  group enjoyed.
* **Know where every game is**: record games you lend out, borrow (with a due-back date reminder) or cannot play
  because of missing pieces, so you are never offered a game that is not on your shelf.

GameVault runs on Windows, macOS and Linux with Java 25, and keeps your collection in a plain text file that you
can read and edit.
